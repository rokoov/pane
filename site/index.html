Notes
Features

Built for the trackpad you already use.

No keyboard shortcuts to learn and no window to drag to an edge. Swipe where your fingers already are.

Halves, quarters, full screen

Eight gestures: left and right halves, fill the screen, minimize, and the four quarters on the diagonals.

A live preview

A blurred preview grows out of the window and shows where it will land. Swipe back to cancel.

Across monitors

Swipe toward an edge the window already fills, and it moves to the next monitor on that side.

Swipe anywhere with ⌥

Hold Option and swipe anywhere on screen to move the active window, no title bar needed.

Scrolling stays scrolling

Pane only acts on a swipe over the active window's title bar. Every other scroll goes straight to your apps.

Halves, then thirds

On a single screen, swipe toward the same edge again and the window goes from a half to two thirds to one third.

Feel the snap

A light click in the trackpad each time the preview jumps to a new layout. Turn it off in Settings if you prefer.

Settings that matter

Swipe length, the preview, haptics, the ⌥ mode and launch at login, plus a clear view of the Accessibility permission.

Private and native

No analytics, no account, no tracking. A small native Swift app, open source under MIT.

Install

Running in a minute.

  1. Download and drag

    Get the latest Pane DMG, open it and drag Pane to Applications.

  2. Open it once

    Pane isn't notarized by Apple yet, so macOS asks first:

    • Open Pane and click Done on the warning.
    • Go to System Settings → Privacy & Security and click Open Anyway.

  3. Allow Accessibility

    macOS asks to let Pane control your computer. Pane needs it to read and move windows, and uses it for nothing else.

FAQ

Questions before you install.

Is Pane free?

Yes, completely. The code is MIT licensed on GitHub, and there is nothing to buy.

Is it safe?

The whole app is open source, so anyone can read what it does. It has no analytics and no account, and the only network request it ever makes is when you click Check for updates, which asks GitHub for the newest version number. Each release lists the SHA-256 checksums of its downloads, so you can check what you got.

Why does it need Accessibility access?

macOS only lets apps read and move other apps' windows through Accessibility. Pane uses it to find the active window and set its size and position. It listens to scroll gestures to spot a swipe and leaves every other scroll alone.

Which window does a swipe move?

Always the active window, the one you're working in. Swipe on its title bar, or hold ⌥ to swipe anywhere on screen.

Does it work with a mouse?

Pane is made for two-finger swipes on a trackpad. A regular scroll wheel doesn't send swipes, so it won't trigger anything.

How is it different from Swish?

Swish is a paid app with many more gestures. Pane does one thing: snap the active window with a swipe on its title bar. It is free and open source.

Which Macs does it run on?

Any Mac on macOS 13 Ventura or later, with Apple silicon or Intel.

Updating from an earlier version?

Quit Pane, drag the new version from the DMG into Applications to replace the old one, and allow Accessibility again. macOS treats each version as a new app because Pane isn't signed with a paid Apple Developer ID.

macOS asks for Accessibility again after an update.

Pane is signed ad hoc rather than with a paid Apple Developer ID, so macOS sees each version as new. Remove Pane from the Accessibility list, or run tccutil reset Accessibility com.rokoov.pane in Terminal, and allow it again.

How do I uninstall it?

Choose Quit Pane from its menu bar icon and move it to the Trash. To also remove its permission, run tccutil reset Accessibility com.rokoov.pane in Terminal.
